# 🌈 Rainbow Tylenol Maker

정해진 틀(노트·화면 컷·자막 연출)에 내 영상·소리 클립을 슬롯마다 끼워 넣어 합성 영상을 만드는 웹 에디터입니다.
틀은 앱에 들어 있고, 소스 파일은 각자 컴퓨터에서 준비해서 넣습니다. 파일은 어디에도 업로드되지 않습니다.

👉 **바로 쓰기: https://tansan7271.github.io/rainbow-tylenol-maker-web/**

## 쓰는 법

1. 페이지를 엽니다. 처음에는 **영상 테스트**(🎬)를 켜면 슬롯이 알파벳 카드로, 자막이 가나다로 보여서 틀의 구조를 볼 수 있습니다.
2. 오른쪽 **악기 슬롯**에서 슬롯의 ✎ 버튼을 누릅니다. **📁 파일 추가**로 내 영상(또는 소리) 파일을 넣고, 시작점과 소리 구간을 정합니다.
   - 슬롯마다 영상과 소리를 다른 파일에서 가져올 수 있습니다.
   - **기준 음정**을 클립 원래 음높이에 맞추면 멜로디대로 음이 바뀝니다. 🎵 자동 감지를 써도 됩니다.
3. 오른쪽 **자막** 칸에 원하는 글자를 적습니다. 비워 두면 가나다가 나옵니다.
4. 위쪽 **원곡**에서 반주로 깔 원곡을 고릅니다.
   - **내 파일**: 미리보기와 mp4 내보내기에 모두 들어갑니다.
   - **유튜브 원본 소리**: 미리보기 전용입니다. mp4에는 들어가지 않고 싱크가 조금 흔들릴 수 있습니다.
5. **💾 저장**하면 이 브라우저에 저장됩니다. **⤓ JSON**으로 파일로 받아 두거나 다른 컴퓨터로 옮길 수 있습니다.
6. **🎬 mp4 내보내기**로 영상을 만듭니다.

**⇆ 비교** 페이지에서는 내 버전과 유튜브 원본을 나란히 놓고 프레임 단위로 볼 수 있습니다.

## 처리 모드

| 모드 | 설명 |
|---|---|
| **브라우저** (기본) | 설치할 것이 없습니다. 크롬·엣지·최신 사파리를 권장합니다. 영상은 mp4(H.264)/webm이 가장 잘 열립니다. |
| **ffmpeg 도우미** | 내 컴퓨터의 ffmpeg를 씁니다. 대부분의 형식(mkv 등)을 열 수 있고, 프레임 추출과 내보내기가 더 빠릅니다. |

ffmpeg 도우미 쓰는 법 ([Node.js](https://nodejs.org) 23 이상, [ffmpeg](https://ffmpeg.org) 필요):

```bash
git clone https://github.com/tansan7271/rainbow-tylenol-maker-web
cd rainbow-tylenol-maker-web
npm install
npm run helper -- --media ~/Videos/내소스폴더
```

도우미를 켠 채로 페이지를 새로고침하면, 위쪽 **처리** 메뉴에서 ffmpeg 도우미를 고를 수 있습니다(자동이면 알아서 고릅니다).
도우미의 소스 폴더에 있는 파일이 목록에 나오고, 내보낸 mp4는 `.helper/exports/`에 저장됩니다.

## 개발

```bash
npm install
npm run dev        # http://localhost:5317
npm run build      # dist/ (GitHub Pages 배포용)
```

- Vite + TypeScript (프레임워크 없음)
- 화면은 박(beat)에 대한 순수 함수로 그려서, 미리보기·비교·내보내기가 같은 그림을 냅니다 (`src/visual.ts`).
- 틀은 `templates/*/template.json`에 있습니다. 슬롯·노트·화면 컷(`shots`)·자막 묶음·자막 이벤트·자막 칸이 들어 있습니다.
- `main`에 푸시하면 GitHub Actions가 Pages로 배포합니다.
